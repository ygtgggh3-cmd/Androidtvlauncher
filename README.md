# Launcher TV Lite

Launcher estilo Google TV para TV boxes viejos (~512 MB de RAM, Android 4.4+).

- Pestañas arriba: **Inicio**, **Aplicaciones**, **Multimedia**
- Inicio: filas de tarjetas redondeadas (favoritos, recientes, accesos a multimedia)
- Multimedia: menú propio (dispositivos USB/SD/interna y filtros Videos/Música/Fotos), explorador de carpetas y reproductor integrado
- Mantener OK o tecla Menú sobre una app: Abrir, Anclar a Inicio, Info, Desinstalar
- Sin dependencias (sin AndroidX/Compose/Leanback) y sin layouts XML

El APK se compila solo en la pestaña **Actions** (artefacto `LauncherTVLite-apk`).
